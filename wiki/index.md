# 番茄鐘工作法（Pomodoro Technique）知識庫索引

本知識庫由 5 篇原始資料經討論、結構化整理與一致性檢查後建立，作為教學 HTML 簡報（`slides.html`）之唯一知識來源。

## 知識條目目錄
1. **[01_core_concepts.md](./01_core_concepts.md)** — 核心定義與時間節奏（對應 `raw/01_origin_and_core.md`）
   - 創始背景、時間盒概念、25 分鐘專注 + 5 分鐘短休息基準。
2. **[02_standard_workflow.md](./02_standard_workflow.md)** — 標準執行四步驟與長休息規則（對應 `raw/02_four_steps.md`）
   - 選任務 → 計時 25 分鐘 → 畫 X 紀錄 → 休息；每 4 輪長休息 15～30 分鐘。
3. **[03_interruption_handling.md](./03_interruption_handling.md)** — 不可分割性與中斷處理原則（對應 `raw/03_interruptions.md`）
   - 禁止暫停、中斷即作廢；內部中斷速記法、外部中斷四字訣。
4. **[04_task_estimation.md](./04_task_estimation.md)** — 任務拆解與合併策略（對應 `raw/04_task_planning.md`）
   - 大任務（大於 5～7 顆）拆小、小任務（小於 1 顆）合併、每日 8～12 顆產能參考。
5. **[05_pitfalls_and_scope.md](./05_pitfalls_and_scope.md)** — 新手常見誤區與適用邊界（對應 `raw/05_pitfalls.md`）
   - 三大常見錯誤（滑手機休息、拖延停手、盲目衝量）與適用／不適用情境。
